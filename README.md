# Dr. Sam Merriaki - Orthopedic Medical Clinic Website

A modern, responsive, and SEO-optimized website for **Dr. Sam Merriaki**, an experienced orthopedist based in Mumbai, Maharashtra, India.

## 🏥 Features

- **Modern Medical Aesthetics**: Custom teal/slate healthcare theme with clean typography pairing (Spectral Serif + Inter Sans).
- **Comprehensive Sections**:
  - Header with sticky navigation & mobile menu
  - Hero section with trust metrics & quick CTAs
  - About Dr. Sam Merriaki (Qualifications, Experience, Philosophy)
  - Specializations (Fracture care, joint management, sports injuries, spine care, pediatric orthopedics)
  - Treatments & Services breakdown
  - Why Choose Dr. Sam Merriaki
  - Interactive Appointment Booking Form with client-side validation
  - Patient Testimonials carousel with auto-rotation
  - Clinic Information & Working Hours schedule
  - Frequently Asked Questions (FAQ) Accordion
  - Contact Section with direct communication form
  - Footer with legal & medical compliance disclaimer
- **SEO & Performance Optimized**:
  - Schema.org `Physician` JSON-LD Structured Data
  - Sub-second page load times (< 60 kB gzipped bundle)
  - OpenGraph social media sharing metadata

## 🛠️ Tech Stack

- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **Vite**
- **Lucide React** (Icons)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/doctor-website.git

# Navigate into project directory
cd doctor-website

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build for production
npm run build

# Preview production build locally
npm run preview
```
